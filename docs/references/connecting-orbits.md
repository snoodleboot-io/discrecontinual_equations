- **[Bader1987]** G. Bader and U. Ascher. *A new basis implementation for a mixed order boundary value ODE solver*. SIAM J. Sci. Stat. Comput. 8(4), 483-500, 1987. DOI [10.1137/0908047](https://doi.org/10.1137/0908047); code COLNEW, <https://www.netlib.org/ode/colnew.f>. Used in: `connecting_orbit.ConnectingOrbit.solve`, `NotConvergedError`, `OrbitResolution` (subroutine `CONTRL`: converged when `|dz_i| <= tol (|z_i| + 1)`; a relaxation factor below `RELMIN = 1e-3` or the iteration limit returns `IFLAG = -2`, no solution). Also used in: `periodic_orbit.PeriodicOrbit._jacobian` (COLNEW's `colnew.f`, argument list of subroutine `COLNEW`: the user supplies the Jacobian `DFSUB`, `df(i,j) = dfi/dzj`, and the code never differences the field - the precedent for taking the monodromy's `df/dx` exactly, DEQ-128). Checked against `colnew.f` from netlib.
- **[Beyn1990]** W.-J. Beyn. *The numerical computation of connecting orbits in dynamical systems*. IMA Journal of Numerical Analysis 10(3), 379–405, 1990. DOI 10.1093/imanum/10.3.379. Bibliographic record checked (Crossref); the text was not reached, and the normalisation's number (4.4) is the one AUTO-07p's `homcont.f90` (`PRJCTN`) cites. Used in: `continuation.connecting_orbit.HomoclinicOrbit`, `HeteroclinicOrbit` (projection boundary conditions on a truncated interval, exponentially small truncation error); `continuation.homoclinic_curve.HomoclinicCurve` (the count of projection conditions, one per stable and one per unstable eigenvalue, is what `EigenvalueCountError` guards); `continuation.connecting_orbit.CollocationResidual` (the truncation error decays exponentially; the abstract was read, and the quadratic-miss estimate in `_manifold_miss` is this package's own leading-order analysis, not taken from the paper); seeded by `continuation.homoclinic_shooting.HomoclinicShooting`. The eigenbasis normalisation (4.4) that HomCont applies is not used here.
