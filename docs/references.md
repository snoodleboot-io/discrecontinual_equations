# References

Every algorithm in the library cites the primary source it implements, in its docstring's `References:` section and on its guide page. This page collects those works, grouped by area. Keys (`AuthorYear`) match the docstrings.

Where we found an error in a published formula, or deliberately depart from the printed text, the entry says so, and so does the docstring.
